Project Lost Legacy - Bringing TU19 Down to TU0 via Downporting

This project is based on source code of Minecraft Consoles (SMART CMD)

The current goal of Project Lost Legacy is to bring back the feel of TU0 (Beta 1.6.6) by downporting TU19.

Currently these are the features changed:
- no sprinting, XP or Hunger (needs rework)
- hit to shear (thanks to Str1k3r)
- a Creative mode 
- no UI Slider or World size slider (locked to classic to match TU0)
- a brand new logo and panorama
- over 100 new splash texts
- classic SFX
- classic Textures
- cheat codes
- a stipped down survival crafting menu

Known Issues:
- world can be resized after creation
- JUST DONT USE BOTTLES OF ENCHANTING PLS (the effects are weird)
- Fishing rods float a lil bit
- Map Texture doesn't show

I'll be working on more updates often, so stay tuned :D
